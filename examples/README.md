# BazLang Example Programs

Example programs demonstrating BazLang features and classic BASIC games.

## Running Examples

```bash
./run.sh examples/games/racer.bas
```

## Demos

| Program          | Description                              |
|------------------|------------------------------------------|
| `demo/cube.bas`  | 3D rotating Rubik's cube                 |
| `demo/life.bas`  | Conway's Game of Life cellular automaton |
| `demo/torus.bas` | 3D rotating torus (doughnut)             |

## Games

| Program               | Description                                             |
|-----------------------|---------------------------------------------------------|
| `games/blackjack.bas` | Classic card game - try to get 21 without going bust    |
| `games/hammurabi.bas` | Resource management game (1968 classic by Doug Dyment)  |
| `games/hangman.bas`   | Guess the hidden word before the man is hanged          |
| `games/racer.bas`     | Avoid the walls as the road twists and turns            |
| `games/wumpus.bas`    | Hunt the Wumpus - classic cave exploration game         |
