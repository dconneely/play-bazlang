# BazLang Example Programs

Example programs demonstrating BazLang features and classic BASIC games.

## Running Examples

```bash
./run.sh examples/games/mastermind.bas
```

## Games

| Program                         | Description                                            |
|---------------------------------|--------------------------------------------------------|
| `games/blackjack.bas`           | Classic card game - try to get 21 without going bust   |
| `games/connect4.bas`            | Connect 4 against the computer                         |
| `games/dice_game.bas`           | Higher or Lower - guess the next dice roll             |
| `games/draughts.bas`            | Draughts (Checkers) against the computer               |
| `games/guess.bas`               | Guess a secret number between 1 and 100                |
| `games/hammurabi.bas`           | Resource management game (1968 classic by Doug Dyment) |
| `games/hangman.bas`             | Guess the hidden word before the man is hanged         |
| `games/life.bas`                | Conway's Game of Life cellular automaton (160x50 grid) |
| `games/lunar_lander.bas`        | Land the spacecraft safely on the moon                 |
| `games/mastermind.bas`          | Guess the secret 4-digit code (digits 1-6)             |
| `games/maze.bas`                | Navigate through a 5x5 maze to reach the exit          |
| `games/nim.bas`                 | Take sticks from piles - last one to take loses        |
| `games/racer.bas`               | Avoid the walls as the road twists and turns (80x25)   |
| `games/rock_paper_scissors.bas` | Classic game against the computer                      |
| `games/tictactoe.bas`           | Tic-Tac-Toe against the computer                       |
| `games/wumpus.bas`              | Hunt the Wumpus - classic cave exploration game        |

## Demos

| Program                  | Description                                        |
|--------------------------|----------------------------------------------------|

## Maths

| Program                  | Description                                        |
|--------------------------|----------------------------------------------------|
| `math/binary.bas`        | Decimal to binary conversion (0-255)               |
| `math/factorial.bas`     | Calculate N! using iteration                       |
| `math/factors.bas`       | Find all factors of a number                       |
| `math/fibonacci.bas`     | Generate Fibonacci sequence up to N terms          |
